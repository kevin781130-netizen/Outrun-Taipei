## 獨立 CHAIN6 數值、時間與設計理由

| 行為 | CHAIN5 | CHAIN6 |
| --- | --- | --- |
| 真正結束漂移後橫向慣性 | 立即以一般抓地 `17.6/s` 拉回目標位移速度 | 在合理高速／路面抓地下開始 `0.29s` 回正過渡：初始響應 `3.8/s`，隨時間自動回到 `17.6/s` |
| 回正時的瞬時轉向控制 | 一般循跡 | 過渡初始暫時降低至多 12% 的新轉向幅度，逐漸恢復 |
| 出彎視覺姿態 | 一出漂即立刻顯示抓地時的車頭角 | CHAIN6 最多保留 ±7.5° 的微幅尾滑視覺偏角，從物理側向速度計算並隨同一個 0.29 秒計時衰減，不會增加實際位移 |
| 外側失控／剎車 | 既有邊界及制動 | 有煞車、抓地 `<0.8` 或速度 `<90` 時，立刻停止延長橫向慣性；道路邊界／撞擊照常處理 |
| 新漂的集氣倍率 | CHAIN4 的側滑角與持續時間倍率 | 漂移年齡 `0.06–0.36s` 額外由 35% 平滑提升至 100%；0.06 秒內仍可微量集氣 |
| 左右長反甩換側 | CHAIN5 斷續過渡處理，維持 `isDrifting` | 沿用 CHAIN5 物理，不重設漂移年齡；換側準備期在原降低充能倍率外，再保守乘以 `0.84` |
| 完成合格長漂後的小回速 | `0.42s×21 km/h/s`，不與 N2O 疊加 | 原樣保留；「回正慣性」**不等於**另一個加速獎勵，不增加庫存 |

另外，原有「放油再補油」的 Moment Boost 準備窗口在 CHAIN6 也需符合 **持續 ≥0.4 秒、曾達 ≥9.5° 滑角** 的合格漂移；短暫或微幅點漂不再能以收尾反覆刷小噴。CHAIN5 與更早版本的原窗口規則不變。

回正過渡只在 **isDrifting 變成 false** 的那次實際漂移完成事件開始，不會在中途反甩左／右時重複授予。剎車、路肩低抓地與低速禁用可減少惡意卡住無敵滑行的空間。車體仍受 lane bounds、hard barrier 與碰撞檢查。
