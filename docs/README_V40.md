# 台北極速傳說 V40 — Taipei OutRunners Fusion

V40 的方向不是把 V34 或 V39 單純覆蓋，而是重新分工：保留 V34 的街機色彩、台北街景密度與場景氣氛，保留 V39 的立體車身、道路透視、車頭方向 / 實際行進方向分離、輸入與路線系統，再重新校正甩尾。

## V40 取用的優點

**從 V34 回來的部分**
- 15 路線的高彩度天空 / 地面配色重新拉回 V34 的辨識度。
- 路邊物件出現頻率提高，重新強調台北騎樓、山景、沿海、夜市、高架與霓虹小物的節奏。
- 市民大道高架不再只有灰階，恢復藍紫夜色、黃 / 青護欄節奏。
- 加回 V34 那種「畫面邊緣一直有東西經過」的街機速度感；部分市區與水岸會出現檳榔攤等台灣小物。

**保留 V39 的部分**
- 六款車沿用 rigid 3D 車體投影，不用斜切 2D 車尾假裝側面。
- 車身朝向（yaw）與實際行進方向分離，甩尾時看得到真正側面，但路線仍可控。
- V39 的道路立體感、坡度、地標世界定位、路線選擇、電台、車庫、D / R 與 Z → A 氮氣系統保留。
- 外觀改裝不改競技性能；V40 成績使用新的 40.0 規則分組，不沿用 V39 物理成績。

## V40 甩尾校正

V39 最大的問題是「系統在替玩家決定何時滑、何時回正」。V40 改成直接的 arcade power slide：

- `方向 + Shift` 在約 82 KM/H 以上可進漂。
- Shift 只觸發一次很短的重心轉移，不會長按就持續偷偷煞車。
- 同向轉向用來增加 / 維持角度；短反打先修正實際走線，不會立即把甩尾判死。
- 持續大反打才會進入回正；Shift 起漂後放開約 0.18 秒也會自然收尾。
- 回正時車身角、滑移角與橫向速度分開衰減，避免 V39 那種車尾被公式拖著走的感覺。
- 有效側滑仍可集氮氣；乾淨出彎保留短暫出彎推力。
- 最高速度規則維持 V39：HIGH 280、氮氣 300 KM/H。

實際手感仍建議用你的鍵盤 / 手把再跑一次，因為甩尾最後 10% 的差異通常來自按鍵、搖桿死區與螢幕更新率。

## 操作

- `W / ↑` 油門；`S / ↓` 煞車。
- `← / →` 或 `J / L` 轉向。
- `方向 + Shift` 動力甩尾；短反打修線；放 Shift 回正。
- `A` 前進、`Z` 倒退；高速 `Z → A` 使用甩尾能量氮氣。
- `Space / E` 切換 LOW / HIGH（AT 可自動換檔）。
- `P` 暫停、`G` 車庫、`T` 路線、`M` 電台。

## 驗證

- JavaScript 已做語法檢查。
- 使用 Chromium 實際載入 HTML，完成 START → 選台 → 倒數 → 加速 → Shift 進漂 → 短反打 → 放開回正流程。
- 實測中約 161 KM/H 入漂後，可穩定進入側滑；短反打降低車身角而維持漂移，回中後約半秒收乾淨。
- 尚未代替你的實機手感測試；手機、實體手把與音訊延遲仍建議自行確認。

所有車輛、人物、建築與程式圖像沿用本專案原創內容；「OutRunners」僅作為街機節奏與操控目標參考，未使用原作素材。
