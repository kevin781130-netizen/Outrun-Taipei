# V59 反打甩尾實作（獨立、選用測試）

Track：Legacy Stable 的明確操控改版需求，在 V59 分支隔離開發；main、正式入口不變。本步沒有新增 Unity 專案、地圖或模型。

## 如何選用

從這個分支啟動靜態伺服器，開啟 `index.html?handling=v59`。頁籤附加「V59 反打測試」。不帶參數仍為 V58 的原操控；參數在啟動時固定，不能在比賽途中切換。

- 補油＋轉向＋點按煞車或 Shift 起甩，原入口保留。
- 車身向彎內偏轉時，朝相反方向反打並補油，可持續保持滑移。反打不再有 0.16 秒強制結束，也不會自動把滑移方向翻轉。
- 反打幅度增加，車身角與側滑量逐漸減少，讓類比手把能修線；同方向加舵則增加原有旋轉需求。
- 方向回正持續約 0.24 秒進入收尾。反打中放油超過約 0.18 秒、其他滑移中放油超過約 0.40 秒進入收尾；角度隨既有阻尼回正。這些是獨立設計的測試數值，不是參考遊戲的參數。
- 收尾、低速、離開有效路面、撞車使用原有重置與恢復流程。前輪仍採方向輸入，車身與行進方向仍分開計算。
- 集氮、氮氣加速及出彎補油小噴沿用既有流程；未加入額外撞車處罰。

操作變化獨立記錄為 `H59.1`：本機分段最佳與街機榜 key 增加 `:H59.1`，不覆蓋 V58 成績。競賽基礎規則仍為 53.0；不把視覺版本假裝成操控版本。尚未完成多人公平性或電競驗收。

## 實作與驗證

`index.html` 新增選用的 `stepCountersteerDrift59` 與固定 profile dispatcher。原 `stepBrakeDrift`、`stepArcadeMotion`、DRIFT51 常數保持原始碼指紋；保留兩套可比較的操控，不用修改舊測試基準隱藏差異。

- `tests/v59-countersteer.cjs`：24 組左右向、30/60/120 Hz、回正/放油、模型與真實 update 模擬；反打持續 1.5 秒、集氮、加速共存、有限數值、鏡像、穩態幀率差、暫停與重置、成績隔離。另測類比修線遞進、撞車一次重置。
- `tests/v56-drift-replay.cjs`：原 7 組確定性回放及指紋；本次另與提交 0287e46 中的實際 HTML 比較，預設舊操控物理狀態完全相符。
- `tests/v56-drift-browser.cjs`：新增選用 URL 的真實鍵盤左右反打、WebGL 車身與前輪方向相反、放油回正及截圖。這些必須由有 Chromium/WebGL 的環境執行，不把腳本存在當成通過。

本步未發布，所以未驗證對應的部署畫面與手感。正式網址目前仍是 main 的 V58，不能用它冒充 V59 驗收。真正手感、實機 FPS、真實道路上的長距離修線仍需試玩；模擬成功只證明所列行為。

參考僅採高層操作概念，程式與數值獨立實作。3D 追車角色、台北地理與模型匯入仍是後續工作，未包含在本步。
