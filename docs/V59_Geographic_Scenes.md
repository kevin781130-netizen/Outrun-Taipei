Track：現有網頁版 Legacy Stable 的獨立 V59 測試分支；共享 JSON 設定可供後續其他引擎移植。本步沒有 Unity 移植，也不修改 main 或公開入口。

## 已接入的範圍

以 `?handling=v59` 選用。新增 `data/world-v59/scene-profiles.json` 與 `RouteGeography.cjs`，按原版 2D 地標順序選擇環境。分區界線使用地標錨點的中點，是**街機場景編排，不是真實道路座標或實際里程**。

原本 15 條路線、27 個地標、全部分岔、彎度、坡度、碰撞走廊與交通資料保留；新資料只改渲染環境。沒有下載或匯入 OSM 道路幾何、實測高程、現成城市模型。

## 保守處理與限制

- 官方資料可確認市民高架與環東大道的真實高架走廊，但原賽道沒有 WGS84 道路中心線、OSM way ID 或逐段橋梁標籤。2B 已明確以市民高架為主題，保留原橋面；4C 的混合路段**尚不能定位哪一段對應真實環東高架，因此本步先呈現地面**，不捏造橋段。後續需由真實道路幾何及標籤決定橋梁區間。
- 河岸／河口水面有有限寬度及對岸；海面延伸到視距外；港池有碼頭與船。九份遠海放在坡地下方，貓空／陽明山不套海面。
- 水面在畫面左側是保留可讀性的美術編排，**不代表已核對實際行車方向與河岸左右側**。
- 2D 壓縮串聯的地標順序沒有擅自更動；關渡→北投、饒河→內湖→河岸均保留原版遊戲次序，不宣稱是實際連通賽道。
- 4C 原先的渲染橋下落差已移除，地標與街廓貼合道路周圍地面；原道路高度與幾何沒有重寫成測量值。
- 岩石、茶列、坡地屋群、碼頭均為原創程序幾何，使用固定實例池與現有地標視線留空區。沒有新增第三方素材或執行期網路依賴。

## 驗證

`tests/v59-geography.cjs` 檢查 15 路線／27 錨點的環境映射、地面／高架限制、河流／河口／海洋分類、特有物件、緩衝池容量、有限矩陣、遊戲 RNG 與原賽道幾何／輸入不變、預設版分流不變。

`tests/v58-taipei-browser.cjs` 保留 V58 全套畫面回歸，另新增 V59 的 27 地標地景、5 夜景、3 手機視窗共 35 張真實 WebGL 畫布影像。它們供人工檢視，不能單憑檔案非空就判定美觀或地圖正確。

本步未部署；公開網站仍不能作為此版本的視覺驗收。真實道路中心線、逐橋對應、地形高程、行車方向／地標方位、實際距離及實機手感/FPS 仍需後續驗證。
