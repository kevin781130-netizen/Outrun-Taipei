# V59 原創 3D 撞車追車演出

Track：現有網頁版 Legacy Stable 的明確演出升級，在 V59 獨立分支完成；沒有 Unity 移植。本步不修改 main、不發布正式入口、不匯入第三方角色或原作素材。

## 選用與行為

在這個分支以 `index.html?handling=v59` 啟動。一般入口仍維持原有操控與碰撞呈現；V59 測試入口同時選用上一階段的反打操控與本次追車演出。

實際碰撞會觸發原有 `triggerCrash`、`updateCrash`。`v57SceneFrame` 只把 `crashSequence.anim` 與 `side` 複製到渲染輸入。新模組讀取此時鐘，沒有自己的倒數、碰撞判定、扣分、扣時、復活或角色 AI。

演出節奏沿用儲存庫中原創 2D 角色流程：

| 動畫時鐘 | 演出 |
| --- | --- |
| 0–0.72 | 車輛誇張翻滾、彈起；兩人相隔 0.12 秒飛出 |
| 約 1.15–1.65 | 落地暈眩、星星繞頭 |
| 約 1.65–3.60 | 大幅擺腿與揮手，追向滑走的車輛，帶起塵土 |
| 約 3.60–4.08 | 兩人先後跳回座位，角色縮入車內 |
| 4.10 | 車回到一般渲染姿態；實際中斷仍為原有 2.9 秒 |

這是原創低模喜劇角色、獨立 3D 姿態與路徑。參考只限高層喜劇概念，沒有使用外部遊戲 ROM、程式、角色、動畫或精確參數。

## 檔案與實作

- `src/rendering/CrashChase.cjs`：純時鐘取樣函式、兩個有關節的誇張比例角色、共用幾何/材質、固定塵土池。啟動後重用物件；LOW 減少塵土實例；可重複安全清理。
- `src/rendering/Full3DScene.cjs`：角色與車輛沿既有道路姿態定位，陰影保留地面高度；恢復駕駛立即重置演出。3D 建立使用獨立視覺亂數，不推進交通/遊戲 RNG。
- `index.html`：只有 V59 渲染快照新增 crash 資料；原碰撞/分數/時間函式未改。
- `tools/build-hybrid.cjs` 與 `assets/hybrid-renderer.js`：離線打包新模組。

## 驗證範圍

`tests/v59-crash-chase.cjs` 驗證 1,644 個時鐘取樣、四階段、左右車輛鏡像、重複渲染/暫停、塵土池、幾何與材質清理、遊戲 RNG 隔離、全場景車輛塗裝替換與恢復。實際遊戲更新對照確認 V59 與預設版的撞車次數、恢復幀數/速度、扣時、分數與冷卻完全一致。投影測試檢查桌面及窄視角四個代表時刻的兩名角色邊界；它不是視覺驗收。

`tests/v56-drift-browser.cjs` 新增 16 張真實 WebGL 圖：桌面/手機視窗、左右撞擊、翻滾/暈眩/追車/登車。測試以實際 `update` 推進撞車時鐘，渲染不得修改遊戲狀態，暫停時不前進；恢復仍為 2.9 秒、118 km/h。影像從渲染後的真實 WebGL 畫布讀取，不用模擬 GPU 像素。

本步尚未發布，所以正式網址仍不是此版本；部署視覺未驗證。CI 圖像檢查與真實裝置手感/FPS 應分開記錄，不把投影、單元測試或 CI 成功當成部署畫面已驗收。台北地理/地標模型整合不包含在本步。
